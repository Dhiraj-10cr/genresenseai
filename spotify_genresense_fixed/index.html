How Song Search Works

1

Memory Substring Search

Query 114,000 Spotify tracks in memory by song title and optional artist with candidate disambiguation.

2

Feature Vector Extraction

Extracts the matched song's exact tempo, loudness, danceability, energy, and acoustic stems from Kaggle dataset.

3

Instant Probability Classification

Evaluates through the trained classifier returning top genre, certainty percentage, and multi-class distribution.

GenreSense AI is trained directly on the open Kaggle Spotify Tracks Dataset (114,000 tracks). It uses a calibrated Multi-Class Ensemble Classifier trained on 9 key acoustic dimensions: tempo, danceability, energy, loudness, duration, valence, acousticness, speechiness, and instrumentalness.
